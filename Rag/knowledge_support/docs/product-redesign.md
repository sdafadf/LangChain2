# 校园智助：功能与界面重设计

## 已确认方向与依据

用户已确认围绕教师教学、学生学习、行政办公、知识管理和系统设置重新设计。保留 Streamlit、原 Embedding、原 ChatModel 和 Docker Milvus，继续采用问题向量检索资料后生成答案，不建立持久历史问答库。

参考 Anthropic `frontend-design`：用真实岗位内容组织视觉层次，先定义字体/配色/布局，再实现；控制装饰，检查真实截图。当前截图显示侧栏技术配置挤占导航、顶部横幅占据首屏、导入和分析结果纵向分离，跨页面缺少可继续处理的任务。

## 信息架构与任务闭环

| 入口 | 核心任务 | 操作闭环 |
| --- | --- | --- |
| 工作台 | 选择岗位、继续本次会话成果 | 进入任务 → 查看进度 → 返回编辑 |
| 教师教学 | 学情分析与教学设计 | 明确选择数据来源 → 校验 → 统计 → 带入薄弱项 → 生成草稿 → 审核导出 |
| 学生学习 | 资料内答疑与学习指导 | 选择课程资料范围 → 选择讲解方式 → 提问 → 核对引用 → 继续学习 |
| 行政办公 | 流程咨询与文稿整理 | 选择流程咨询/纪要/通知 → 输入真实条件 → 生成 → 编辑审核 → 导出 |
| 知识中心 | 分类资料管理 | 查找资料 → 上传预览 → 生成向量入库 → 验证可检索 → 确认删除 |
| 系统设置 | 模型配置与连接诊断 | 查看原配置 → 显式应用变更 → 测试服务 → 查看部署说明 |

工作台显示的成果只存在当前会话，服务重启后不保留，不称为永久任务库。资料范围基于 Milvus 已上传文档，不虚构完整课程/班级管理系统。

## 实现范围

- 从全局侧栏移出模型地址和密钥表单，保留单独设置入口；配置更改只有点击应用才生效。
- 上传与合成样例明确二选一，避免选择真实文件后继续分析示例。分析摘要跨页面保留，改变输入或阈值时使旧结果失效。
- 教师直接从学情页进入教学设计，自动携带薄弱知识点；输出可编辑，并加入当前会话成果列表。
- 学生支持分步讲解、提示引导、自测练习三种回答策略，策略明确传入生成提示词；文档选择落实为 Milvus 检索过滤。
- 行政流程与文稿独立子页。文稿默认空白，可显式填入合成示例；生成结果统一编辑、审核和导出。
- 知识中心可按分类和名称筛选，显示文档及片段数；资料不足或断连时给出明确下一步。
- 所有已有数据和原 Milvus 集合保留，不修改数据库结构。

## 视觉系统

继承青绿色主色，采用清晰、安静的教学办公工作台，而非宣传落地页。

- 主色 #197B70，正文 #20334D，辅助正文 #65758B，画布 #F5F7FA，表面 #FFFFFF，边线 #E2E8EF。
- 中文使用系统雅黑/苹方等本机字体；页标题 28–30px，区块标题 18–20px，正文 14–16px，说明 12–13px。
- 桌面导航约 240px，主区域宽度不超过 1240px；紧凑页头后直接呈现任务操作。
- 内容区使用 8/16/24/32px 间距；相关表单共用一个分组，不把每段文字做成独立卡片。
- 仅使用 Streamlit 原生 Material 图标；不用装饰插画、英文全大写眉题或大面积渐变。
- 窄屏按自然阅读顺序堆叠，表格横向滚动，表单标签不隐藏，保留键盘焦点。

## 验证

原业务/embedding/Milvus 测试继续运行；补充文档范围过滤、讲解策略传递、跨页学情状态、草稿编辑、设置显式应用与上传样例切换验证。使用浏览器检查桌面及窄屏，检查设置参数不再挤占主界面。真实模型验证仅用已知合成资料，测试不发送非示例文档到新目的地。
