# 功能演示脚本

所有画面使用合成资料，不展示学校名称、校徽、账户和密钥。

1. 展示教学工作台与三种运行模式，说明当前是离线工具模式。
2. 点击分析学情，展示 4 名合成学生、12 条记录、67.5% 总得分率，以及函数参数 55% 的薄弱项。
3. 展示教学行动建议和学情汇总导出；说明具体生成练习需本地模型。
4. 切换知识库管理，加入合成资料；展示课程与行政分类。
5. 学习答疑点击循环问题，展开资料原文，说明离线结果是检索原文。
6. 行政办公查询设备借用材料，再整理会议纪要与待办。
7. 展示脱敏预览和下载入口，结束于使用与部署说明。

本地生成模型未验证时，不在视频中伪造生成效果。演示视频展示真实界面操作，模型生成部分需在模型安装后补录。
