# DeepAgents 智能任务与自定义技能

2026-09-23：按用户批准的“新增智能任务入口 + 可视化技能管理”方案实施。

## 结构

- `campus_skills.py`：校验标准 SKILL.md，读取内置技能，保存本机角色技能与启用状态。只接收 Markdown 与文本参考资料。
- `campus_harness.py`：复用 ModelConfig，使用 DeepAgents 的任务规划、按需技能读取和状态文件系统；将校园知识库及当前学情摘要包装为工具。
- `campus_agent_page.py`：智能任务、执行记录、结果下载、技能编辑/导入/导出/试运行。
- `campus_navigation.py`：教师与学生都可进入智能任务、我的技能；原有入口保留。

## 执行与数据

每次执行加载最新启用技能的快照；只有这些内容和本次提供的文本进入 StateBackend。模型没有主机文件系统、shell、环境变量和配置文件读取工具。技能目录只读；临时工作文件只保留在此次执行状态。

检索工具沿用 Milvus/Embedding，学生只能检索课程分类，教师可以检索课程和行政。学情工具只在教师端提供，只读当前会话的汇总结果。用户技能不能增加工具权限。当前应用仍是本机角色分区，不是账号认证；同角色保存的技能可由本机其他会话使用。

首版单代理循环，禁用默认委派，以便限制调用次数。单次最多 10 次主模型调用、20 次工具调用，模型请求超时 60 秒，不自动切换模型。展示模型调用次数、计划、实际工具调用和引用；不展示模型私有推理。任务失败保留输入并显示可操作提示，不伪装成功。

技能导入先预览再保存，支持名称、触发描述、步骤、参考文本。保存到 `data/user_skills/<role>/<name>/SKILL.md`；内置技能可查看并复制为新技能。启停与修改下次运行生效。学生技能与教师技能分目录，任务历史分会话/角色保存。任务结果可下载 Markdown。

## 验收

保留原 67 项离线回归；新增技能校验、目录边界、启停/重载、角色工具范围、真实 DeepAgents 图执行与模型 HTTP 模拟、失败与限额、页面编辑/运行测试。最后使用现有 DeepSeek 配置做合成任务实时验证，不发送真实学生材料。验证依赖与项目 requirements 一致，再备份并同步项目。
