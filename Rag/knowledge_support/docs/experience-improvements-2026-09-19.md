# 校园助手体验问题修复

依据：2026-09-19 学生/教师实际体验报告，以及用户要求按报告完善项目。

采用保留现有 Streamlit 页面和服务的局部修复。相比仅改文案，此方案同时修复状态和任务路径；相比重建多账号平台，范围集中且不会改变现有数据结构。

1. 空公共资料时终止不可完成的答疑路径，提供个人资料、练习和刷新入口；区分搜索无结果，支持清空搜索。
2. 将已启用练习与草稿分开显示。已启用快照始终可下载；相同版本不重复启用；审核结论按内容版本保存在业务会话状态，修改后失效；草稿修改不改变当前练习或作答。
3. 教学草稿默认简洁版，提示模型尊重具体篇幅与题数；完整版按需选择。草稿默认Markdown预览，编辑视图继续保存到原草稿，原导出审核保持有效。
4. 个人资料的存储选项改成“仅本次会话/长期保存”，兼容已有会话的旧标签；继续明确说明长期库的共享范围和资料发送。
5. 使用 viewer 工具栏和 headless 服务配置关闭开发引导，CSS只针对开发提示兜底；修正说明文字颜色和父容器不透明度。

验证：原有57项回归加6项体验回归，共63项通过。另以真实浏览器检查空资料跳转、说明文字、教案生成与预览、已启用练习展示。模型行为以真实调用结果单独记录，不把模拟测试当作服务验证。

应用方式：先备份，逐一校验原文件仍与备份一致，再仅覆盖此次修改的文件。保留模型密钥、服务地址和资料目录。原项目不是Git仓库，因此不创建提交。
