# 补练流程实现设计

按已确认的网易JBGS-2026-05方向实施。教师教学新增“补练与反馈”：选择已有学情中的知识点，检索课程资料，一次模型调用生成两个单选题；无资料时停止。另提供显式标注的循环边界合成演示。

每题包含四个选项、答案、提示、解析和资料编号。教师可逐字段编辑，保存后核对并启用。内容变化产生新版本；学情变化后禁止启用旧草稿。学生每题最多两次作答，第一次错误显示提示，结束后显示解析；判分由Python执行，不运行学生代码，不将答对比例称为掌握率。

完整练习包可导入导出，包含答案，明确用于自学而非保密考试。导入须校验大小、结构、题数、答案范围、重复选项和引用；导入文件不能自行声明教师审核通过。教师在当前会话重新审核后才能启用。反馈仅导出版本和选择记录，无身份字段；教师导入后重新判分，核对顺序、次数和版本，不相信文件自带分数，也不将可编辑文件视为正式成绩凭证。

沿用当前会话状态、模型和Milvus，不新增长期学生数据库。campus_practice.py处理业务，campus_practice_page.py处理页面，campus_pages.py仅增加入口。验证原回归、边界用例、完整AppTest流程以及真实浏览器。源码在工作区测试后回写原项目，回写前检查原文件哈希并备份。
